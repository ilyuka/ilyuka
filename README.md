# Ilya Shulepov

Independent researcher and software engineer focused on reproducibility,
research software, and machine-learning software engineering.

### Current work

I'm developing **[MLReproMutate](https://github.com/ilyuka/MLReproMutate)** —
research software for mutation testing of reproducibility-relevant safeguards in
machine-learning research code.

The project studies whether repository validation workflows detect controlled
changes to random seeds, dependency constraints, data splitting, and
cross-validation configuration.
